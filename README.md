# SignalDesk

**Live demo:** https://luvbuniz.github.io/signaldesk/

SignalDesk is a lead-discovery and outreach workspace for service businesses where missed calls can mean missed revenue.

The first version helps you:

- review public call-handling signals
- prioritize high-fit leads
- prepare a personalized first message
- track outreach and follow-ups

It is designed for human-reviewed outreach, not mass automated messaging.
